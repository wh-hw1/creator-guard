# 🛡️ 크리에이터 권리 지킴이 (프로토타입 v0.3)

청년 크리에이터를 위한 AI 기반 권리 보호 서비스의 웹 프로토타입입니다.
유튜브 영상의 댓글을 불러와, 대한민국 법률을 기준으로 **법적으로 검토할 만한 쟁점 후보**를 정리합니다.

> **v0.3:** 댓글 하나를 선택해 모욕·명예훼손·협박 쟁점을 분석하는 AI 기능(Claude Sonnet 5.5)을 추가했습니다.
> AI는 범죄 여부를 판단하지 않습니다. 검토할 쟁점과 추가로 확인할 사실을 알려줄 뿐입니다.

## 주요 기능

1. 서비스 소개 화면
2. 유튜브 영상 URL 입력
   - 지원 형식: `youtube.com/watch?v=...`, `youtu.be/...`, `youtube.com/shorts/...`
3. **댓글 분석 시작**을 누르면 최상위 공개 댓글을 최대 50개 불러옵니다. (YouTube Data API v3)
4. 댓글을 선택하면 작성자, 작성 시각, 댓글 ID 등 상세 정보를 표시합니다.
5. **이 댓글 AI 분석하기**를 누르면 모욕·명예훼손·협박 쟁점별로 다음 내용을 보여 줍니다.
   - 검토 수준
   - 근거가 된 표현
   - 판단 기준 적용
   - 쟁점이 인정되는 사정과 부정되는 사정
   - 추가로 확인할 사실
   - 관련 법령·판례 링크

## AI 분석 기준

### 원칙
- **범죄 여부를 단정하지 않습니다.** 결과는 "검토 필요성 높음 / 검토 필요 / 검토 필요성 낮음 / 해당 없음" 중 하나로만 표시합니다.
- **일반적인 비판은 악성 댓글로 분류하지 않습니다.**
  - 영상 내용이나 행동에 대한 비판은 표현이 거칠어도 "일반 의견·비판"으로 분류합니다.
  - 무례하거나 저속한 표현만으로는 모욕으로 보지 않습니다.
- **확인된 근거만 인용합니다.** 아래 목록은 국가법령정보센터 원문으로 확인한 것만 담았습니다([legal_basis.py](legal_basis.py)). AI는 이 목록의 ID 중에서만 근거를 고를 수 있습니다.
- **코드로 한 번 더 검증합니다.**
  - AI가 "근거 표현"으로 인용한 문구가 실제 댓글에 없으면 그 문구를 버립니다.
  - 근거 표현이 하나도 남지 않으면 검토 수준을 낮춥니다.
- 댓글만으로 알 수 없는 사실은 "추가로 확인해야 할 사실"로 따로 정리합니다. 예: 사실인지 허위인지, 같은 사람이 반복해서 썼는지, 실제 인물이 특정되는지.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `app.py` | 화면(UI)과 사용자 흐름 |
| `youtube.py` | URL에서 영상 ID 추출, 댓글·영상 정보 가져오기 (YouTube API) |
| `analyzer.py` | Claude API로 댓글의 법적 쟁점 분석 (결과 형식 지정 + 코드 검증) |

| `.gitignore` | GitHub에 올리지 않을 파일 목록 (실제 키가 든 `secrets.toml` 포함) |

## 1. API 키 발급받기

### YouTube API 키

1. <https://console.cloud.google.com> 에 Google 계정으로 로그인합니다.
2. 위쪽 프로젝트 선택 메뉴에서 **새 프로젝트**를 만듭니다.
3. **API 및 서비스 → 라이브러리**에서 `YouTube Data API v3`를 검색하고 **사용**을 누릅니다.
4. **API 및 서비스 → 사용자 인증 정보 → 사용자 인증 정보 만들기 → API 키**를 누르면 키가 만들어집니다.
5. (권장) 생성된 키의 **API 제한사항**에서 `YouTube Data API v3`만 허용하도록 설정합니다.

### Anthropic(Claude) API 키

1. <https://console.anthropic.com> 에 가입하고 로그인합니다.
2. **Billing**에서 결제 수단을 등록하고 크레딧을 충전합니다.
   - 사용한 만큼 비용이 나갑니다. 아래 "비용" 항목을 참고하세요.
3. **API Keys → Create Key**로 키를 만들고 복사합니다.
   - 키는 만들 때 한 번만 보이므로 바로 Streamlit Secrets에 넣으세요.

> ⚠️ API 키는 비밀번호와 같습니다. 코드, README, GitHub 이슈, 채팅 등 어디에도 직접 붙여넣지 마세요.

## 2. API 키 등록하기

### Streamlit Community Cloud에 배포한 경우 (추천)

1. <https://share.streamlit.io> 에서 내 앱 오른쪽의 **⋮ → Settings → Secrets**로 들어갑니다.
2. 아래처럼 두 줄을 입력하고 **Save**를 누릅니다.

   ```toml
   YOUTUBE_API_KEY = "발급받은_YouTube_API_키"
   ANTHROPIC_API_KEY = "발급받은_Anthropic_API_키"
   ```

3. 앱이 자동으로 다시 시작되며, 1분 정도 지나면 적용됩니다.

### 내 컴퓨터에서 실행하는 경우

1. `.streamlit/secrets.toml.example` 파일을 복사해 같은 폴더에 `secrets.toml`로 저장합니다.
2. `secrets.toml` 안의 값을 실제 API 키로 바꿉니다.
   - 이 파일은 `.gitignore`에 들어 있어 GitHub에 올라가지 않습니다.

환경 변수 `YOUTUBE_API_KEY`, `ANTHROPIC_API_KEY`로 설정해도 동작합니다.

## 3. 실행 방법

### 웹에서 실행 (Streamlit Community Cloud)

1. <https://share.streamlit.io> 에 GitHub 계정으로 로그인합니다.
2. **Create app**을 누르고 이 저장소, `main` 브랜치, `app.py`를 선택한 뒤 **Deploy**를 누릅니다.
3. 위의 **API 키 등록하기**를 따라 Secrets를 설정합니다.

### 내 컴퓨터에서 실행 (Python 3.10 이상)

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 비용

- **YouTube Data API:** 하루 무료 사용량(기본 10,000 단위) 안에서 무료입니다. 영상 하나를 조회할 때 약 2 단위(댓글 1 + 영상 정보 1)를 씁니다.
- **Claude API:** 댓글 하나를 분석할 때마다 비용이 듭니다. 모델은 Claude Sonnet 5.5이고, 요금은 입력 100만 토큰당 $2, 출력 100만 토큰당 $10입니다.
  - 버튼을 눌렀을 때만 분석하고, 한 번 분석한 댓글은 결과를 다시 보여 주기만 합니다.
  - 매번 같은 기준 설명(시스템 프롬프트)은 캐시해서 비용을 줄입니다.
  - 정확한 비용은 Anthropic Console의 Usage 화면에서 확인하세요.
  - 비용을 더 줄이려면 [analyzer.py](analyzer.py)의 `EFFORT`를 `"medium"`으로 낮출 수 있습니다.
